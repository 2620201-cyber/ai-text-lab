🔬 AI 텍스트 변형 실험실

텍스트의 변형 조건을 통제하고, 원본과 변형본의 차이 및 판별 결과를 기록하는 연구용 도구입니다.

① 원본 텍스트 입력

현재 버전은 실제 언어 모델 토큰이 아닌, 공백으로 구분한 단어 단위를 임시 토큰으로 사용합니다.

② 토큰 확인

텍스트를 입력한 뒤 토큰 분석을 실행하세요.

③ 통제된 변형 입력

5번째, 10번째, 15번째처럼 5개 단위의 위치를 실험 대상으로 표시합니다. 변형 후보는 연구자가 직접 입력합니다.

④ 결과 비교

⑤ 띄어쓰기 변형 실험

띄어쓰기 조건은 단어 변형과 별도로 입력하고 비교하세요.

⑥ 판별 결과 기록

외부 판별 도구의 결과를 직접 입력합니다. 이 프로그램은 외부 서비스와 자동 연결되지 않습니다.

주의: 이 도구는 실험 조건과 텍스트 차이를 기록하기 위한 보조 도구입니다. 결과는 사용한 판별 도구와 데이터, 검사 조건에 따라 달라질 수 있습니다.
