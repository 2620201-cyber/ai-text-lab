AI 텍스트 탐구 실험실

텍스트의 표현과 형식 변화에 따른 AI 탐지 결과를 비교하는 실험 도구

1. 원문 입력

실험에 사용할 원본 문장을 입력하세요.

2. 단어 변경 실험

공백을 기준으로 단어를 구분하며, 5번째 단어마다 변경 대상으로 표시합니다. 추천 표현은 참고용이며 문맥에 적합한지 확인한 후 선택하세요.

먼저 원문을 입력하고 텍스트 분석하기를 눌러주세요.

3. 원문과 수정문 비교

원문
원문이 여기에 표시됩니다.
수정문
수정문이 여기에 표시됩니다.

4. 띄어쓰기 변경 실험

단어 자체는 유지하고 공백 형태만 변경합니다.

띄어쓰기 변경 결과가 여기에 표시됩니다.

5. AI 탐지 결과 기록

외부 AI 탐지 도구에서 확인한 결과를 직접 입력하세요.
